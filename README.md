# 方寸台球 —— 3D台球仿真游戏
基于Unity引擎的3D写实台球仿真游戏，依托URP管线渲染，结合PhysX物理引擎还原台球碰撞、滚动、减速等物理效果。

## ✨ 项目介绍
- 开发工具：Unity + Visual Studio，Blender制作3D场景模型
- 核心脚本：`BallManager`、`QueueController`
- 个人职责：团队主力编码，独立完成模型制作、游戏逻辑编写、功能调试与性能优化
- ✅ 项目成果：完整可运行Demo，物理规则贴近真实台球，交互体验流畅，掌握小游戏完整开发流程
